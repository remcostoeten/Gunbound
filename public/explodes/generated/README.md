# Generated Attack Sprite Sheets

These sprite sheets are original, repo-generated attack VFX assets created with
`scripts/generate-attack-sprite-sheets.mjs`.

They are not ripped Gunbound assets. They are mobile-specific replacements that
aim for the same readable artillery-fantasy roles:

- `dragon-fire.svg`
- `snow-frost.svg`
- `mage-rune.svg`
- `turtle-shell.svg`
- `frog-bubble.svg`
- `sate-sonar.svg`
- `knight-blade.svg`
- `trico-horn.svg`

Each sheet contains 16 horizontal frames at 128x128.
