# Gunbound UI SFX

These UI one-shots are original generated WAV assets created with
`scripts/generate-ui-sfx.mjs`.

They cover the UI categories identified from the Pixabay UI sound effects search
surface: click, primary action, confirm, select, open, close, notify, error, and
denied action.

Reference source candidate:
- https://pixabay.com/sound-effects/search/ui/

No Pixabay audio files are committed here. The files in this directory are
procedural, repo-local replacements so the UI can be wired and tuned without
depending on external download availability.
