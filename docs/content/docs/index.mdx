## Working Rhythm

- Use reducers as the source of truth for gameplay mutations.
- Keep subscription boundaries explicit so the client receives only what each screen needs.
- Treat auth and account recovery as part of the game loop, not a separate afterthought.
- When in doubt, open the AI helper and ask against the current docs corpus.
