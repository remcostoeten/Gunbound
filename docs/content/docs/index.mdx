## Working Rhythm

- Start with `bun run dev` from the repo root for normal app work.
- Regenerate bindings after any schema or reducer change.
- Keep client state in the client and shared state in SpacetimeDB.
- Use the docs pages to confirm the current project flow before you touch a subsystem.
