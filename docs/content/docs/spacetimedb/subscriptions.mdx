## Overview

Gunbound uses the SpacetimeDB React SDK. **`useTable()` creates and manages subscriptions** — the app provider does not call `subscribeToAllTables()`.

When a reducer mutates a table, subscribed hooks receive updated rows and components re-render.

## Basic usage

```typescript
import { useTable } from 'spacetimedb/react';
import { tables } from '@/features/game/spacetime';

function PlayerList() {
  const [players, isReady] = useTable(tables.player);

  if (!isReady) return <div>Loading players…</div>;

  return (
    <ul>
      {players.map((p) => (
        <li key={p.identity.toHexString()}>{p.name}</li>
      ))}
    </ul>
  );
}
```

`isReady` is **subscription applied** — initial snapshot received. It is not a general-purpose loading flag for reducer calls.

## Filtered queries

Subscribe to a subset server-side when the table is large or the view is narrow:

```typescript
const waitingQuery = tables.room.where((r) => r.status.eq('waiting'));
const [waitingRooms, ready] = useTable(waitingQuery);
```

For small tables or UI-specific shaping, filtering in JavaScript after `useTable(tables.room)` is also fine (see `useLobbyRooms`).

## Identity lookups

const me = players.find(

## Domain hooks

Prefer hooks in `src/features/lobby/spacetime/` over scattering `useTable` in UI:

### useLobbyRooms

- Subscribes to `room`, `room_member`, `player`.
- Filters out `ended` rooms, computes member counts, resolves host names.
- Exposes `createRoom`, `joinRoomByCode`, `quickJoin`.

### useRoomSession(roomId)

- Joins `room_member`, `player`, `chat_message` for one room.
- Exposes `sendChat`, `setReady`, `selectMobile`, `leave`.

### useMatchmakingQueue

- Subscribes to `waiting_player`.
- Calls `joinQueue` / `leaveQueue`.

## Social table visibility

`friendship`, `friend_request`, and `room_invite` are filtered on the server so each client only receives rows they participate in. You still use normal `useTable(tables.friendship)` — the filter is applied server-side.

## Re-render model

1. Reducer mutates a table on the server.
2. SpacetimeDB pushes the delta to subscribed clients.
3. `useTable` updates its row array.
4. React re-renders consuming components.

## Performance

- Memoize derived lists with `useMemo` when filtering or mapping large arrays.
- Prefer indexed server filters in reducers over `.iter()` on big tables.
- Multiple components can call `useTable` on the same table; the SDK deduplicates subscriptions.

## Debugging

```typescript
useEffect(() => {
  console.log('rooms', rooms);
}, [rooms]);
```

Check websocket traffic in DevTools and server logs with `bun run spacetime:logs`.
