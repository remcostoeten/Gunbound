## Tables

### Player

Persistent identity and profile stats. Created on first `onClientConnected`; never deleted.

```typescript
export const Player = table(
  {
    name: 'player',
    public: true,
    indexes: [
      { accessor: 'player_is_online', algorithm: 'btree', columns: ['isOnline'] },
      { accessor: 'player_level', algorithm: 'btree', columns: ['level'] }
    ]
  },
  {
    identity: t.identity().primaryKey(),
    name: t.string(),
    createdAt: t.timestamp(),
    updatedAt: t.timestamp(),
    displayNameSetAt: t.timestamp().optional(),
    isOnline: t.bool(),
    lastSeen: t.timestamp(),
    xp: t.u64(),
    level: t.u32(),
    loginStreak: t.u32(),
    longestStreak: t.u32(),
    lastLoginDay: t.u64(),
    totalWins: t.u32(),
    totalLosses: t.u32(),
    totalRoundsPlayed: t.u32(),
    isAdmin: t.bool().optional(),
    country: t.string().optional()
  }
);
```

- `name` starts empty; set via `setPlayerProfile` / registration.
- `level` is derived from XP on the server (`computeLevel`).
- `isOnline` / `lastSeen` track lobby presence (`setLobbyPresence`, connect/disconnect hooks).
- Mobile selection lives on `room_member`, not on `player`.

### Credential

Public table of password-encrypted session tokens for cross-device login.

```typescript
export const Credential = table(
  {
    name: 'credential',
    public: true,
    indexes: [{ accessor: 'credential_identity', algorithm: 'btree', columns: ['identity'] }]
  },
  {
    username: t.string().primaryKey(),
    identity: t.identity(),
    encryptedToken: t.string(),
    createdAt: t.timestamp(),
    updatedAt: t.timestamp()
  }
);
```

`encryptedToken` is a JSON bundle: `{ v, iter, salt, iv, ct }` (see [Authentication](/docs/spacetimedb/auth)).

### Room

Two-player lobby / match container.

```typescript
export const Room = table(
  {
    name: 'room',
    public: true,
    indexes: [
      { accessor: 'room_code', algorithm: 'btree', columns: ['code'] },
      { accessor: 'room_host_identity', algorithm: 'btree', columns: ['hostIdentity'] },
      { accessor: 'room_status', algorithm: 'btree', columns: ['status'] }
    ]
  },
  {
    id: t.u64().primaryKey().autoInc(),
    code: t.string(),
    hostIdentity: t.identity(),
    status: t.string(), // waiting | starting | in_match | ended
    seed: t.u64(),
    mapType: t.string(),
    targetScore: t.u32(),
    roundLimit: t.u32(),
    turnDurationMode: t.string().optional(),
    createdAt: t.timestamp()
  }
);
```

- **Capacity is 2** (`ROOM_MAX_MEMBERS` on the server). Member count is derived client-side from `room_member` rows.
- `mapType`: `rolling`, `canyon`, `crater`, `ridge`.
- `turnDurationMode`: `timed` or `infinite`.
- Codes are reusable after a room reaches `ended`.

### RoomMember

Join table while a player occupies a room.

```typescript
export const RoomMember = table(
  {
    name: 'room_member',
    public: true,
    indexes: [
      { accessor: 'room_member_room_id', algorithm: 'btree', columns: ['roomId'] },
      { accessor: 'room_member_identity', algorithm: 'btree', columns: ['identity'] }
    ]
  },
  {
    id: t.u64().primaryKey().autoInc(),
    roomId: t.u64(),
    identity: t.identity(),
    slotIndex: t.u32(),
    teamIndex: t.u32().optional(),
    mobileType: t.string(), // empty string until selected
    isReady: t.bool(),
    joinedAt: t.timestamp()
  }
);
```

### Round & RoundEvent

Deterministic match state. A `round` row is created by `startRound`; `round_event` rows are appended by `recordRoundEvent` for replay sync.

```typescript
export const Round = table(/* roomId, seed, status, startedAt, endedAt, winnerIdentity */);

export const RoundEvent = table(/* roundId, tick, actorIdentity, kind, payload, createdAt */);
```

Event kinds include `battle_move`, `battle_switch_weapon`, `battle_switch_item`, `battle_fire`, `battle_surrender`. Payload is opaque JSON validated server-side.

### RoundStat

Per-player stats for one round (keyed by `roundId`, not `roomId`).

```typescript
{
  roundId: t.u64(),
  playerIdentity: t.identity(),
  damageDealt: t.u32(),
  shotsFired: t.u32(),
  directHits: t.u32(),
  xpAwarded: t.u32()
}
```

### ChatMessage & LobbyChatMessage

- `chat_message` — in-room chat (`senderIdentity`, max 200 chars).
- `lobby_chat_message` — channel-scoped lobby chat (`channel` 1–8).

### Social tables

- `friend_request` — pending/accepted/declined requests.
- `friendship` — directed buddy edges (`ownerIdentity` → `buddyIdentity`).
- `room_invite` — invite to join a room.

These tables are public for codegen but filtered per subscriber:

```typescript
export const friendshipOwnerVisibility = spacetimedb.clientVisibilityFilter.sql(
  'SELECT * FROM friendship WHERE ownerIdentity = :sender'
);
// Similar filters for friend_request and room_invite
```

### WaitingPlayer

Matchmaking queue. `joinQueue` pairs the caller with another waiting player and creates a room for both.

### AppSetting

Public key/value runtime flags (`key` PK, `value` string). Writes go through admin reducers when needed.

## Admin players

`Player.isAdmin` gates privileged reducers. Bootstrap admin is granted to credential usernames `remco` and `remcostoeten` (case-insensitive), checked via credential rows rather than display names.

## Design patterns

### Identity as foreign key

Use `.toHexString()` when comparing identities in TypeScript or reducer logic.

### Room status machine

```
waiting → in_match → waiting (next round) → ended (last member left)
```

Client constant: `ROOM_STATUS` in `src/features/game/spacetime/room-status.ts`.

### Auto-increment IDs

Insert with `id: 0n`; the server assigns the real ID on the returned row.

### Valid mobile types

Server set: `armor`, `knight`, `dragon`, `snow`, `trico`, `aduko`, `mage`, `nak`, `turtle`, `frog`, `sate`.

## Indexes

Index `accessor` names follow `{table}_{column}` (e.g. `room_member_room_id`). Use `.filter(value)` in reducers instead of full-table `.iter()` when possible.
